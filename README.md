# tia-plugin

Marketplace local da **Tia**, assistente de produto para Product Managers, como plugin do Claude Code.

- Plugin: [`plugins/tia/`](plugins/tia/README.md) — instalar, primeira sessão, atualizar, desinstalar.
- Mudanças: [`plugins/tia/CHANGELOG.md`](plugins/tia/CHANGELOG.md) · decisões: [`plugins/tia/docs/decisoes.md`](plugins/tia/docs/decisoes.md).

```bash
claude plugin marketplace add <caminho deste repositório>
```

```bash
claude plugin install tia@tia-marketplace
```
