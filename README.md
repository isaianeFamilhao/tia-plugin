# ada-plugin

Marketplace local da **Ada**, assistente de produto para Product Managers, como plugin do Claude Code.

- Plugin: [`plugins/ada/`](plugins/ada/README.md) — instalar, primeira sessão, atualizar, desinstalar.
- Mudanças: [`plugins/ada/CHANGELOG.md`](plugins/ada/CHANGELOG.md) · decisões: [`plugins/ada/docs/decisoes.md`](plugins/ada/docs/decisoes.md).

```bash
claude plugin marketplace add <caminho deste repositório>
```

```bash
claude plugin install ada@ada-marketplace
```
