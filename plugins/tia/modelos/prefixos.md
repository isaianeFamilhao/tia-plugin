# Prefixos de domínio das regras (do time)

Toda regra da Base é `RN-<PREFIXO>-NNN`, com prefixo de três letras maiúsculas. Domínio novo: acrescente uma
linha aqui antes de criar o arquivo de regras.

| Prefixo | Domínio | Arquivo |
|---|---|---|
| `RN-XXX` | [a definir] | `<area>/regras/<tema>.md` |
